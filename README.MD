## Overview

This collection covers a wide range of Python topics, from basic data structures to object-oriented programming (OOP). Each file represents a specific concept or exercise that helped me understand Python better.

## Topics Covered

### Basic Data Structures
- **Lists**: Comprehensions, generators, and manipulations
- **Dictionaries**: Key-value pairs and operations
- **Tuples**: Immutable sequences
- **Sets**: Unique collections and set operations

### Functions and Functional Programming
- **Functions**: Defining and using functions
- **Lambda Functions**: Anonymous functions
- **Filter and Map**: Functional programming concepts

### Object-Oriented Programming (OOP)
- **Classes and Objects**: Basic class definitions
- **Inheritance**: Single and multiple inheritance
- **Polymorphism**: Method overriding and dynamic behavior
- **Aggregation and Composition**: Object relationships
- **Special Methods**: `__init__`, `__str__`, etc.

### Exercises and Practice
- Various exercises to reinforce learning
